## Productivity Hub + Intelligent Analytics + Workspace Performance Center

### Context

TaskFlow currently includes: Authentication, Roles, Workspaces, Tasks CRUD, Activity Feed, Notifications, Dashboard, JSON Server, Clean Architecture, React, TypeScript, Vite, TanStack Query, Responsive Design.

You MUST NOT break any existing functionality. You MUST NOT remove any working code. You MUST NOT introduce regressions. You must reuse the current architecture. You must preserve all Clean Architecture principles. You must follow the patterns already implemented in the project.

---

### Autonomous Mode

You have full authorization to: Create files, Modify files, Execute commands, Install dependencies, Update routes, Create components, hooks, services, repositories, Execute migrations.

DO NOT ask for permissions. DO NOT request confirmations. DO NOT stop execution.

If multiple solutions are possible: Automatically choose the best solution based on Scalability, Performance, Clean Code, UX, Maintainability, Enterprise Architecture.

---

### Main Objective

Transform TaskFlow into an intelligent productivity platform.

I DO NOT want a dashboard with widgets. I want a REAL PRODUCTIVITY HUB.

A central place where users can: Measure productivity, Analyze performance, Detect bottlenecks, Identify critical tasks, Monitor workload, Make informed decisions.

---

### New Menu Option

Add: `⭐ Productivity Hub` — Below Workspaces.

Add a professional icon consistent with the rest of the system. The menu item must respect permissions, light/dark themes, and be fully responsive.

---

### New Route

Create: `/productivity`

Add lazy loading, code splitting, and protect the route using AuthGuard.

---

### Section 1 — Productivity Score

Create a primary indicator.

Calculate dynamically using: Completed tasks, Overdue tasks, Active tasks, Average resolution time, Recent activity, Weekly productivity.

Display: Score (e.g. 92/100), Trend, Variation (e.g. ↑ +8%).

Visually appealing.

---

### Section 2 — Smart Insights

Create an automatic insights engine.

Examples:

- ⚠️ There are 12 overdue tasks.
- ⚠️ John has too many assigned tasks.
- 🚀 Productivity increased by 18%.
- 📈 This workspace completed more tasks this week.
- 🔥 Critical tasks are still pending.

Insights must be generated dynamically. Do NOT hardcode them.

---

### Section 3 — Workload Analytics

Create workload visualization per user.

Display: User, Total tasks, Completed tasks, Pending tasks, Overdue tasks.

Detect: Overload, Underutilization, Uneven distribution. Display visual alerts.

---

### Section 4 — Top Priorities

Automatically generate top priorities sorted by: Priority, Due date, Status, Impact.

Display: Priority, Assigned user, Workspace, Due date.

---

### Section 5 — Workspace KPIs

Display KPI cards: Total Tasks, Completed, Pending, Overdue, Members, Completion Rate, Productivity Index.

Premium design. Smooth animations.

---

### Section 6 — Productivity Trend

Implement a professional chart. Display by Day, Week, Month.

Metrics: Tasks created, Tasks completed, Tasks overdue.

Allow switching between date ranges.

---

### Section 7 — Upcoming Deadlines

Display: Task, Responsible user, Workspace, Remaining days.

Highlight: Today, Tomorrow, Overdue.

---

### Section 8 — Quick Actions

Create panel: New Task, Invite Member, New Workspace, View Analytics, Notifications.

IMPORTANT: All buttons must be functional. DO NOT leave placeholders or buttons without actions.

---

### Section 9 — Advanced Activity Feed

Improve the Activity Feed. Group activities.

Example: *Today — John created 4 tasks. Peter completed 3 tasks. Maria updated 7 tasks.*

Add filters: Today, Week, Month, User, Workspace.

---

### Section 10 — Team Productivity Ranking

Create ranking: 🥇 John, 🥈 Maria, 🥉 Peter.

Calculate using: Completed tasks, Average completion time, Activity level.

---

### Section 11 — Workspace Health Status

Display workspace health: 🟢 Excellent, 🟡 Attention Needed, 🔴 Critical.

Calculate automatically.
