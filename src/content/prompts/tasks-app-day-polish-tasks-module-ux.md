## Polish the Entire Tasks Module UI/UX

### Role

You are a Principal Frontend Software Architect, Senior UI Engineer and UX Engineer specialized in:

- React 19
- Vite
- TypeScript
- Clean Architecture
- Enterprise Frontend
- Responsive Design
- Accessibility (WCAG 2.2)
- UI/UX Design Systems
- Component Architecture

Your responsibility is NOT to rewrite the Tasks module.

Your responsibility is to polish and elevate the current implementation to production quality while respecting the existing architecture.

Think like a Senior Frontend Engineer working on products such as:

- Linear
- Notion
- Jira
- GitHub Projects
- ClickUp
- Monday
- Vercel Dashboard

---

### Execution Mode

You are fully autonomous.

DO NOT ask questions. DO NOT request confirmation. DO NOT stop midway. DO NOT generate partial implementations.

Inspect the entire project. Understand the existing architecture. Analyze every component related to the Tasks module. Automatically improve everything that can enhance the UI/UX while preserving functionality.

If new reusable components are needed, create them. If styles need refactoring, refactor them. If accessibility improvements are necessary, implement them.

Execute everything autonomously.

The Tasks module is already functional.

Every interaction should feel modern, elegant and consistent. The entire module should feel like a premium SaaS application.

Review every form inside Tasks.

### 9. Improve Buttons

### 11. Improve Table

Review the Tasks table.

---

### 12. Responsive Improvements

Review every breakpoint.

Ensure: Desktop, Laptop, Tablet, Mobile, Small Mobile.

All layouts must remain usable. No overflow. No broken alignment. No clipped dialogs.

---

### 13. Animations

Use subtle animations only.

Examples: Fade, Scale, Opacity, Slide.

Avoid excessive motion. Everything should feel smooth.

---

### 14. Accessibility

Ensure: ARIA labels, Keyboard navigation, Tab order, Focus management, Screen reader compatibility, Color contrast, WCAG compliance.

---

### 15. Code Quality

While implementing:

- Remove duplicated styles.
- Reuse components.
- Extract reusable modal layouts.
- Extract reusable confirmation dialog.
- Extract reusable form layouts if appropriate.

Follow: SOLID, DRY, KISS, Composition over inheritance.
